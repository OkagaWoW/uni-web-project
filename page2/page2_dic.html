Эксперимент с DislCryptor

DiskCryptor

DiskCryptor — свободное программное обеспечение с открытым исходным кодом, предназначенное для шифрования всех разделов дисков, включая системные разделы, внешних устройств хранения информации, USB-накопителей, создания зашифрованных CD и DVD а также образов CD/DVD. Разработку DiskCryptor, начатую в 2007 году первоначальным автором ntldr, прекратившуюся в 2014 году, теперь продолжает и развивает DavidXanatos совместно с разработчиками-вкладчиками

Функиции

  • Полнодисковое шифрование (FDE)
  • Шифрование системных и внешних дисков
  • Открытый исходный код

Плюсы программы:

  • Бесплатный и легковесный
  • Высокая скорость шифрования/дешифрования
  • Поддержка нескольких криптоалгоритмов
  • Можно использовать на загрузочных дисках

Минусы:

  • Нет поддержки в новых версиях Windows (разработка прекращена)
  • Нет сертификации ФСТЭК/ФСБ (не подходит для госструктур РФ)
  • Минимальный интерфейс, сложен для новичков
